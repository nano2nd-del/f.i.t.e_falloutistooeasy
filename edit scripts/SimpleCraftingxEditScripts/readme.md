  Sets BNAM to whatever you pick on every selected COBJ record.

  HOW TO USE
  -----------
  1. Select the COBJ records you want in the left pane.
  2. Tools -> Apply Script -> this file.
  3. Make sure "Apply script to selected records" is CHECKED.
  4. Save when done.

  THE SIMPLE CRAFTING KEYWORD NEEDS TO BE ADDED TO YOUR ESP.
they just replace the workbench BNAMs with the relevant script. 

Requires SimpleCrafting and some knowledge of xedit. 

there is no error checking. 

it only replaces what you highlight!!!

uses these keywords:
sc_kywd_CraftbenchWeapons "sc_kywd_CraftbenchWeapon" [KYWD:FE06B006] 
WorkbenchChemlab [KYWD:00102158]
sc_kywd_CraftbenchArmor and sc_kywd_CraftbenchWeapon
